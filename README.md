# Maintenance Page — Anders Luisteren

Lightweight, zero-dependency static maintenance page for **Anders Luisteren** ([andersluisteren.com](https://andersluisteren.com)).

## Features
- **Single-file (`index.html`)**: Inline CSS and SVG with zero external dependencies so it works reliably during outages.
- **Responsive & Accessible**: Clean layout for mobile and desktop with automatic light/dark mode (`prefers-color-scheme`).
- **SEO Safe**: Includes `<meta name="robots" content="noindex, nofollow" />` so search engines do not index the temporary maintenance state.

## Usage
Open `index.html` directly in a browser, or deploy the repository directly to GitHub Pages, Cloudflare Pages, Vercel, Netlify, or an Nginx/reverse-proxy server.
